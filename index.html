Import Stock Count from CSV

Bulk-upload physically counted quantities for one warehouse. Required columns: sku (or name) and counted_qty. Products are matched by SKU first, then by name. Only rows where the counted quantity differs from the current system quantity create a variance. Add an optional unit_cost column (the last purchase price) when loading opening stock for a brand-new warehouse/product — any quantity gained by the count is then costed in at that price, so the warehouse's average cost (and therefore P&L/COGS) starts correct from day one. Leave it blank for a routine recount where you only want to correct quantities, not cost.
